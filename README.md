🦖 Chrome Dino Java Game

A Java-based clone of the Chrome Dino Game, built to demonstrate core game development concepts like game loops, collision detection, and real-time user interaction.

🎮 Gameplay
Press SPACE to jump
Avoid obstacles 🌵
Survive as long as possible to increase your score
🚀 Features
🕹️ Smooth game loop & animations
🦖 Player jump mechanics
🌵 Obstacle spawning system
💥 Collision detection
📈 Score tracking system
⚡ Lightweight and fast performance
🛠️ Tech Stack
Language: Java
Concepts Used:
Game Loop
OOP (Object-Oriented Programming)
Event Handling
Collision Detection
